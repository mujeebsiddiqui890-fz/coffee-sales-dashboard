# ☕ Coffee Shop Sales Dashboard

An interactive data visualization dashboard built in *MS Excel* to analyze coffee shop sales, customer footfall, and product performance.

## 📊 Key Metrics & Insights
* *Total Sales:* 101,373
* *Average Bill:* 4.7
* *Visualizations:* Hourly customer footfall, day-wise sales, product category breakdown, and individual product performance.
* *Interactive Filters:* Slicers for Day Name, Month Name, and Store Location.

## 🛠️ Tools & Features Used
* *Microsoft Excel* (Pivot Tables, Pivot Charts, Slicers, Conditional Formatting)
